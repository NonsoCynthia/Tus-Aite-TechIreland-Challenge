# Tús áite — logo assets

Irish for priority, literally first place. Pronounced **toos AW-cheh**.
Typeface: **Jost** ExtraLight (200), letterspaced 0.14em. Both fadas carry the clay accent.

## Colours

| Role | Hex |
|---|---|
| Ink (primary) | `#122056` |
| Clay (accent — the one being seen next) | `#7A5B4D` |
| Taupe (accent on dark) | `#C4B6A6` |
| Paper | `#FAFAF8` |

Red, amber and green stay out of the brand palette — they belong to the triage categories inside the product.

| PowerPoint, over a light slide | `tus-aite-lockup-navy.png` (transparent) |
| PowerPoint title slide | `tus-aite-slide-title-1920x1080.png` |

| LinkedIn / X company page | `tus-aite-avatar-navy.png` + `tus-aite-banner-1500x500.png` |
| Anything printed or scaled large | the `.svg` marks |

## Rules

- Clear space on all sides equals the cap height of the wordmark.
- Clay marks one element per composition. Used everywhere it stops meaning anything.
- Below 13 px cap height, drop the wordmark and use the mark alone.
- No gradients, glows, drop shadows or outlined variants.
- Never place the mark over a photograph of a patient.
- In any clinical setting the words **decision support** travel with the mark.
